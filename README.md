# Ball Guys · Наполни стакан

Неофициальная самостоятельная браузерная реализация режима Merge из Ball Guys. Без рекламы, аналитики, платежей, билетов и запросов к сторонним сервисам во время игры. Работает с мышью, клавиатурой и сенсорным экраном.

## Игра

- Бросайте шарики в стакан: два одинаковых объединяются в следующий.
- 11 ступеней и увеличивающийся стакан. Очки за слияния: 10, 40, 90, 160, 250 и дальше; комбо показывает сумму цепочки.
- Мягкие шарики сминаются при ударе и под весом соседей, восстанавливают форму и сохраняют площадь. Деформируется сама форма столкновений, а не только рисунок.
- Партия заканчивается сразу, когда хотя бы один шарик выпадает наружу за стенку стакана. Высота стопки сама по себе не завершает игру.
- Очки сохраняются автоматически после выпадения: последний результат, рекорд и общая сумма. Кнопки ручного сохранения очков нет.
- Смена шарика, встряска, подброс и удаление выбранного шара: по 3 использования на партию, бесплатно.
- Партия, открытые шарики, рекорд и настройка звука сохраняются в `localStorage` этого браузера.
- После первого успешного открытия игру можно запускать без сети благодаря Service Worker.
- На компьютере: мышь или ←/→ + пробел. P — пауза. На телефоне: прицельтесь пальцем и отпустите.

## На главный экран iPhone

Откройте [игру](https://khairikhanshr.github.io/ball-guys-merge/) в Safari → «Поделиться» → «На экран Домой». Если есть переключатель «Открывать как веб-приложение», включите его и нажмите «Добавить». Игра откроется отдельной иконкой без панели браузера. На первом запуске с иконки дождитесь загрузки с интернетом, после этого доступна игра офлайн. В самой игре есть кнопка с этой инструкцией.

Прогресс хранится на устройстве. Сохранение из вкладки Safari может не переноситься в отдельно установленную игру; удаление данных браузера удаляет сохранения.

## Локальный запуск

Требуется Python 3 (для сервера) и Node.js 20+ (только для проверок).

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Установка пакетов и сборка не нужны. Для сохранений и офлайн-режима используйте HTTP(S), а не `file://`.

```sh
npm run check
npm test
```

Тесты проверяют слияния и цепочки, защиту от двойного использования шарика, геометрию стакана, выпадение за край и однократное завершение партии, способности, сохранения, время падения, деформацию и устойчивость стопки. Также проверяются иконки iPhone, манифест установки и список ресурсов офлайн-кэша.

## GitHub Pages

Статическая страница публикуется из корня ветки `main`: **Settings → Pages → Deploy from a branch → main / (root)**. Все пути относительные, поэтому игра работает и на проектном адресе GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll. Для обновления достаточно отправить изменения в `main`.

## Устройство проекта

- `core.js` — физика, слияния, начисление очков и проверка сохранений.
- `gel.js` — упругая деформация формы столкновений с сохранением площади и массы.
- `game.js` — рисунки на Canvas, ввод, интерфейс, звуки и сохранение.
- `style.css` — адаптивная компоновка.
- `vendor/matter.min.js` — Matter.js 0.20.0, сохранён локально; лицензия MIT рядом.
- `sw.js` — кэш игры для работы без интернета.
- `assets/` — иконки установки и локальный шрифт Balsamiq Sans (OFL, лицензия рядом).

## Об оригинале

Механика и общий вид изучены по [официальной странице Ball Guys](https://www.ballguys.gg/), [описанию разработчика в Google Play](https://play.google.com/store/apps/details?id=gg.HalfMoon.BallGuys) и предоставленной записи режима Merge. По записи настроены пропорции стакана и шариков, падение до дна примерно за 1,5–1,6 секунды, мягкое приземление, очки и комбо. Это независимая реализация, не официальный продукт Half Moon Studios. Исходный код, графика и звуки оригинала не используются: персонажи рисуются программно, звуки синтезируются в браузере. Закрытые параметры физики недоступны, поэтому совпадение 1:1 не гарантируется. Поведение способностей, не показанных в записи, реализовано самостоятельно. Сетевых рейтингов, игровых покупок и аккаунтов нет.

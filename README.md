# Ball Guys · Наполни стакан

Неофициальная самостоятельная браузерная реализация режима Merge из Ball Guys. Без рекламы, аналитики, платежей и билетов. Игра размещена на GitHub Pages, общий рейтинг — в отдельной базе Sites. Работает с мышью, клавиатурой и сенсорным экраном.

## Игра

- При первом запуске введите имя. Оно запоминается на устройстве; пароль не нужен. Изменить имя можно нажатием на него.
- Все игроки по ссылке участвуют в общем рейтинге по лучшему результату за одну завершённую партию. Топ‑3 виден на игровом экране, по нажатию открывается топ‑10. Нулевые результаты тоже сохраняются.
- Бросайте шарики в стакан: два одинаковых объединяются в следующий.
- 11 ступеней и увеличивающийся стакан. Очки за слияния: 10, 40, 90, 160, 250 и дальше; комбо показывает сумму цепочки.
- Мягкие шарики сминаются при ударе и под весом соседей, слабо отскакивают, восстанавливают форму и сохраняют площадь. После слияния или удаления опоры стопка снова оседает. Деформируется сама форма столкновений, а не только рисунок. Сила смятия и передача удара учитывают соотношение масс: маленький шарик не схлопывает и не подбрасывает большой.
- Прицел свободно перемещается по всей ширине поля: можно намеренно бросить шарик мимо стакана.
- Первый новый крупный шарик в каждой партии показывается в анимированной заставке со звёздами. Несколько открытий подряд показываются по очереди.
- Партия заканчивается сразу, когда хотя бы один шарик выпадает наружу за стенку стакана. Высота стопки сама по себе не завершает игру.
- Очки сохраняются автоматически после выпадения: последний результат, рекорд и общая сумма. Кнопки ручного сохранения очков нет.
- Смена шарика, встряска, подброс и удаление выбранного шара: по 3 использования на партию, бесплатно.
- Фоновая мелодия запускается после первого касания или нажатия клавиши. Нота включает и выключает музыку, динамик — звуки игры. На паузе и при сворачивании музыка останавливается.
- Партия, открытые шарики, рекорд и настройки музыки и звуков сохраняются в `localStorage` этого браузера.
- После первого успешного открытия игру можно запускать без сети благодаря Service Worker.
- Выделение текста, перетаскивание картинок и меню долгого нажатия отключены, чтобы не мешать прицеливанию.
- На компьютере: мышь или ←/→ + пробел. P — пауза. На телефоне: прицельтесь пальцем и отпустите.

## На главный экран iPhone

Откройте [игру](https://khairikhanshr.github.io/ball-guys-merge/) в Safari → «Поделиться» → «На экран Домой». Если есть переключатель «Открывать как веб-приложение», включите его и нажмите «Добавить». Игра откроется отдельной иконкой без панели браузера. На первом запуске с иконки дождитесь загрузки с интернетом, после этого доступна игра офлайн. В самой игре есть кнопка с этой инструкцией.

Партия и ключ профиля хранятся на устройстве. Имя и лучший результат сохраняются в общей базе. Повторный ввод того же имени на другом устройстве создаёт отдельного игрока: вход по имени не служит восстановлением доступа. Непереданные результаты автоматически отправляются при появлении связи. Прогресс хранится на устройстве. Сохранение из вкладки Safari может не переноситься в отдельно установленную игру; удаление данных браузера удаляет сохранения.

## Локальный запуск

Требуется Python 3 (для сервера) и Node.js 20+ (только для проверок).

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Установка пакетов и сборка не нужны. Для сохранений и офлайн-режима используйте HTTP(S), а не `file://`.

```sh
npm run check
npm test
```

Тесты дополнительно проверяют общий рейтинг двух игроков, сохранение максимального результата, смену имени, повторную отправку после офлайна и защиту от потери результата во время отправки. Тесты физики проверяют слияния и цепочки, защиту от двойного использования шарика, геометрию стакана, выпадение за край и однократное завершение партии, способности, сохранения, время падения, деформацию и устойчивость стопки. Также проверяются иконки iPhone, манифест установки и список ресурсов офлайн-кэша.

## GitHub Pages

Статическая страница публикуется из корня ветки `main`: **Settings → Pages → Deploy from a branch → main / (root)**. Все пути относительные, поэтому игра работает и на проектном адресе GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll. Для обновления достаточно отправить изменения в `main`.

## Устройство проекта

- `core.js` — физика, слияния, начисление очков и проверка сохранений.
- `gel.js` — упругая деформация формы столкновений с сохранением площади и массы.
- `discovery.js` — очередь и анимация открытия новых шариков.
- `audio.js` — собственная зацикленная мелодия и звуки игры, созданные в браузере.
- `leaderboard.js` — профиль без пароля, общий рейтинг и повторная отправка результатов.
- `game.js` — рисунки на Canvas, ввод, интерфейс, звуки и сохранение.
- `style.css` — адаптивная компоновка.
- `vendor/matter.min.js` — Matter.js 0.20.0, сохранён локально; лицензия MIT рядом.
- `sw.js` — кэш игры для работы без интернета.
- `assets/` — иконки установки и локальный шрифт Balsamiq Sans (OFL, лицензия рядом).

## Об оригинале

Механика и общий вид изучены по [официальной странице Ball Guys](https://www.ballguys.gg/), [описанию разработчика в Google Play](https://play.google.com/store/apps/details?id=gg.HalfMoon.BallGuys) и предоставленной записи режима Merge. По записи настроены пропорции стакана и шариков, падение до дна примерно за 1,5–1,6 секунды, мягкое приземление, очки и комбо. Это независимая реализация, не официальный продукт Half Moon Studios. Исходный код, графика и звуки оригинала не используются: персонажи рисуются программно, звуки синтезируются в браузере. Закрытые параметры физики недоступны, поэтому совпадение 1:1 не гарантируется. Поведение способностей, не показанных в записи, реализовано самостоятельно. Игровых покупок нет. Общий рейтинг хранит выбранные имена и лучшие результаты. Имя не уникально; ключ записи генерируется на устройстве, на сервере хранится только его хеш. Это дружеский рейтинг: очки рассчитываются в браузере, серверной проверки всей партии нет.

## Общий рейтинг

API: `https://ball-guys-shared-ranking.copperoak2048.chatgpt.site/api`. Страница игры остаётся на прежнем GitHub Pages. В браузер не передаются ключи управления сервером.

- `GET /leaderboard` — до десяти лучших игроков, только публичные поля.
- `POST /players` — регистрация или изменение имени по случайному ключу профиля.
- `POST /scores` — обновление максимального результата; повтор запроса не создаёт дубликатов.

Исходники сервера и миграция базы сохранены в отдельном репозитории Sites, рабочая копия — `.sites/ranking/` (не публикуется на GitHub Pages). Проект: `appgprj_6ad214fe0fc88191a9d7f52fe34b7179`. База D1, привязка `DB`.

Локальная игра на `localhost:4173` использует тестовый API `127.0.0.1:5173`, чтобы проверки не засоряли публичную таблицу. Для запуска тестового API в `.sites/ranking/` выполните `npm run dev -- --port 5173 --hostname 127.0.0.1`. Клиентские проверки запускаются из корня командой `npm test`, серверные — из `.sites/ranking/` командой `node --test tests/api.test.mjs`.
